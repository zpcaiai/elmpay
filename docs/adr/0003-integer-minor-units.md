# ADR-0003: 金额一律使用最小货币单位整数

- 状态：accepted
- 日期：2026-08-18
- 批次：B02
- 决策者：payment-platform-architecture payment-platform-finance
- 关联需求：PAY-REQ-0028
- 关联控制：NN-05
- 取代：无

## 背景

浮点金额在多币种、分账、手续费与汇率换算下会产生不可解释的账本差异；不同币种的小数位（JPY 0 位、TND 3 位）若硬编码为两位会直接算错金额。

## 决策

所有金额以最小货币单位的 64 位整数表示，币种小数位与舍入规则来自受版本控制的货币元数据。禁止在任何层使用 float/double 承载金额。

## 后果

所有对外契约需显式声明币种与最小单位；跨币种展示由前端按元数据格式化。收益是账本可精确重算。

## 备选方案

（a）Decimal 字符串：部分可行，但序列化边界仍易退化为浮点；（b）浮点 + 容差：拒绝，容差在复式账本中不可接受。

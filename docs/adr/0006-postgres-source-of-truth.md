# ADR-0006: PostgreSQL 为事实源，Kafka 只做可重放事件，Redis 不承载最终状态

- 状态：accepted
- 日期：2026-08-18
- 批次：B02
- 决策者：payment-platform-architecture payment-platform-sre
- 关联需求：PAY-REQ-0007, PAY-REQ-0027
- 关联控制：CTRL-008, CTRL-013
- 取代：无

## 背景

需要一个具备强约束、事务与 PITR 的事实源；同时需要可重放的事件流供业务项目与内部消费者使用；缓存必须可随时丢弃。

## 决策

支付状态、幂等记录、Inbox/Outbox 与账本以 PostgreSQL 为唯一事实源。Kafka 承载可重放领域事件但不作为状态权威。Redis 只保存限流、短期缓存与可丢失信号。

## 后果

读写模型需要显式的投影与滞后处理；换来的是任何组件丢失后都可从事实源重建。

## 备选方案

（a）事件溯源为唯一事实源：拒绝，审计与对账查询复杂度过高；（b）Redis 保存幂等记录：拒绝，驱逐会导致重复副作用。

## 验证

B90/B91/B92 的耐久性与故障注入；B95 恢复演练。

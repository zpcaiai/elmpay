# ADR-0008: 密钥由 KMS/HSM/Vault 管理且不落地

- 状态：accepted
- 日期：2026-08-18
- 批次：B02
- 决策者：payment-platform-security
- 关联需求：PAY-REQ-0044
- 关联控制：NN-07, CTRL-006
- 取代：无

## 背景

渠道私钥与商户密钥一旦泄露即可伪造交易与退款；把密钥放在配置文件、环境变量或镜像中会使泄露不可检测且不可撤销。

## 决策

所有私钥与 API 密钥只以 `kms://` 或 `vault://` 引用形式出现在配置中，运行时短期解密，轮换具备重叠窗口、审计与演练。仓库中出现疑似密钥字面量即构建失败。

## 后果

本地开发需要模拟密钥后端；换来的是密钥泄露面从“任何有仓库读权限的人”缩小到“有 KMS 授权的服务身份”。

## 备选方案

（a）加密后提交仓库：拒绝，解密密钥仍需分发；（b）环境变量注入：部分可行，但缺少轮换与审计。

## 验证

`tools/paygov/hygiene.py` 的 `SECRET_*` 扫描、`config.py` 的 `CONFIG_CREDENTIAL_REF`；B20/B21 轮换演练。

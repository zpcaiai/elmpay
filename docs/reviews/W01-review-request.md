## 2. 我自己发现并修掉的四个真缺陷（请复核修法是否恰当）

1. **门禁崩溃 ≠ 门禁拒绝**（B09）。`_vectors()` 遇到损坏元数据时抛 `TypeError`。
   修法：失败关闭返回 `MONEY_VECTORS`。**请检查还有没有别处会崩**。
2. **门禁校验了错误的那份实现**（B09）。`import` 走 `sys.modules` 缓存，
   夹具仓库被真仓库的实现验证。修法：按 `root` 路径加载。
3. **失败模式靠中文关键词匹配**（B14）。规则搜「放行」，把「**不**放行」误判成 fail-open。
   修法：改成结构化枚举 `failure_mode`。**请全仓搜索还有没有别的规则在读散文**。
4. **16 条跨模块外键**（B14）。生成的 DDL 给 `payment_intent.tenant_id → tenant` 建了外键，
   两个服务从此无法独立迁移或分片。修法：改 B08 生成器，跨边界保留列不建约束。
   **请判断：应用层校验缺失是否是更大的风险？**

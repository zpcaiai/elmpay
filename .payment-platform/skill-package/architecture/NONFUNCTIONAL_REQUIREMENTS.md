
# 非功能需求

- 可用性：核心支付入口建议 99.95% 月度目标；状态查询和回调入口独立扩缩容。
- 一致性：资金状态优先正确性，不以低延迟换取未验证成功；最终一致性必须可观察和可补偿。
- 安全：管理员抗钓鱼 MFA；服务 mTLS；密钥 HSM/KMS；零信任授权；严格租户隔离。
- 隐私：最少收集、字段分类、用途限制、删除证明、跨境和地区化策略。
- 可恢复：PITR、跨区域副本、渠道账单重建、Outbox/Inbox 重放和定期演练。
- 可审计：每个资金与权限动作具备主体、理由、前后值、工单和不可篡改证据。
- 可移植：渠道适配器遵循统一契约；业务项目不依赖渠道私有状态。
- 可运维：所有重试、回放、人工修复和配置变更有安全控制与回滚。

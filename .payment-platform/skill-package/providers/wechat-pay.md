
# 微信支付 APIv3 实施指南

优先支持 JSAPI、小程序、Native、H5、App；支持查询、关单、退款、退款查询、交易账单与资金账单。默认直连商户模式；服务商模式必须单独启用监管扩展。

- 使用微信支付 APIv3 官方 SDK；凭证通过 KMS 引用，平台公钥/证书支持重叠轮换。
- 回调使用原始请求体，验证 `Wechatpay-Timestamp`、`Wechatpay-Nonce`、`Wechatpay-Serial`、`Wechatpay-Signature`，随后解密 resource。
- 验签失败必须拒绝；不能对签名探测流量特殊放行。
- 校验商户号、应用 ID、商户订单号、微信交易号、金额和币种；回调和查询冲突时进入人工/查询恢复，不盲目改成功。
- 账单下载链接短期有效，下载后核验哈希；交易账单对支付事实，资金账单对费用/结算，银行流水完成三方核对。

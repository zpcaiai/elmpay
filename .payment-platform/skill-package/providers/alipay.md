
# 支付宝实施指南

优先支持电脑网站、手机网站、App、当面付预创建、小程序；支持查询、关闭、退款、退款查询、账单与异步通知。

- 使用官方 SDK 和证书模式；应用私钥由 KMS/HSM 管理，支付宝公钥证书与根证书受版本控制和轮换监控。
- `notify_url` 必须来自登记配置，禁止请求参数传任意 URL。
- 对异步通知执行官方 RSA2/证书验签，并校验 `app_id`、`seller_id`、`out_trade_no`、`trade_no`、`total_amount`、`trade_status`。
- 同步回跳只展示结果；履约依据为异步通知或服务端查询。
- 对金额字符串先按渠道规则解析为最小货币单位，再与不可变 Payment Intent 金额比较。

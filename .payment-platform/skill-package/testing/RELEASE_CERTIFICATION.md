
# 最终生产认证

B127 认证至少要求：

- 128 个批次完成文件全部通过 Schema 与依赖哈希校验。
- 支付状态机、退款上限、幂等、账本平衡和事件重放属性测试通过。
- 微信与支付宝生产前验收优先通过；Stripe、PayPal、Apple Pay 官方沙箱与域名/证书测试通过。
- 外部渗透测试与红队无未接受 Critical/High；所有接受项有责任人和到期日。
- 生产级备份恢复、PITR、KMS 故障、渠道故障和区域灾难演练通过。
- 连续日终三方对账无未解释资金差异；人工调整均有四眼审批。
- 生产凭证、商户号、域名、Webhook、账单、限额、告警和联系人双人复核。
- 安全、财务、运维、产品和合规责任人独立签署。

认证证明的是特定提交、配置、环境和时间点，不是永久保证。任何密钥、渠道、架构或重大版本变更应触发增量认证。
